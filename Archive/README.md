# 人物档案与日记

独立项目。**与 Chat / Code / Tool 没有任何代码关联。**

- 网页：https://liuyiming2024.github.io/Archive/
- 仓库：**公开**（因为要用 GitHub Pages）

## ⚠ 三条铁律

1. **公开仓库里绝不放数据。** 档案是关于具体人物的私密信息，
   仓库既然公开，数据只能待在数据库里，网页运行时才去取。
   一旦把数据提交进这个库，等于向所有人公开。
2. **显示前先鉴权。** 没权限就一个字都不渲染 ——
   "先渲染再隐藏"是障眼法，数据其实已经到客户端了。
3. **原文永不被覆盖。** 改写写进 `polished` 列，`body` 保持原样；
   整理结果永远新增一版，不覆盖 —— 整理错了能退回。

## 独立性边界

| 项 | 是否共用 |
|---|---|
| 账号（登录、站长判定） | ✅ 共用统一账号体系 |
| 数据 | ❌ 完全独立，只有本项目读写 |
| 前端代码 | ❌ 完全独立，不引用其他项目的任何文件 |

## 三层架构

```
原始随手记（body，永不被改写覆盖）
   ↓ 改写：只润色流畅度，最大程度尊重原文（不加推断、不加评价）
第 1 层 · 大日记（polished）—— 按时间汇集，不分人
   ↓ 提炼 + 分门别类，归到每个人（也可不归属任何人）
第 2 层 · 小日记（profile_notes）—— "今天见到了谁，第二天又和他干了啥"
   ↓ 总体概括
第 3 层 · 个人档案（profile_summaries）—— 大纲概览 / 详细数据 + 相册
```

整理形态五种：时间线 / 分类条目 / 结构化摘要 / 大纲概览 / 详细数据。

## 部署

1. 建表：把 `supabase/schema.sql`（或 `.github/sql/run.sql`，幂等）
   拿到能写数据库的通道执行。
2. Pages：仓库 Settings → Pages → 从 `main` 根目录部署。
