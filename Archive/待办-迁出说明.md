# ⚠ 这里只是暂存区，不是最终位置

`Archive/` 目录里的代码**最终要迁到独立仓库 `liuyiming2024/Archive`**。

## 为什么会在这里

`liuyiming2024/Archive` 已经建好了（公开仓库，Pages 域名
https://liuyiming2024.github.io/Archive/ ），但当前写 token 是精确授权型，
只授权了 Chat / Code / Tool / assets / 主页，**不包含新建的 Archive** ——
读得到（200），写不了（403）。所以先暂存到这里。

## ⚠⚠ 两条重要提醒

**1. 不要给这个目录配 Pages 部署。**
Archive 是公开仓库，这个 assets 仓库如果也是公开的，
把档案页部署出去会多一个入口 —— 而它自己会鉴权，多一个入口就多一处要守的门。
里面的 `pages.yml` 是给将来独立仓库用的，在这个仓库里**不会生效**
（不在仓库根目录），但别把它挪到根目录。

**2. 这个目录里没有任何档案数据。**
数据只在数据库里。公开仓库里一旦出现真实档案内容，等于向所有人公开 ——
这是本项目最不能犯的错。

## 迁出步骤（拿到授权后）

1. 给写 token 加上 Archive 的授权范围，或换新 token
2. 把本目录内容推到 `liuyiming2024/Archive` 根目录
3. 这里整个删掉
4. 开启 Archive 的 Pages（Settings → Pages → main 根目录）
